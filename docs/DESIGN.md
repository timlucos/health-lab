# Дизайн-код «Здоровье Лаб»

Читать перед любым изменением интерфейса. Здесь описано то, что **уже есть в коде** (`app/globals.css`, `components/`, `app/`), и то, о чём владелец просил по стилю и UX (тред проекта, 11–13.10.2026). Новый экран должен выглядеть так, будто он был с самого начала.

Стиль одной фразой: **структура как в iOS «Здоровье», тройные кольца и крупные цифры как в «Фитнесе», цвета зон состояния как в «Профи»** (выбор владельца — стили 1, 3 и 8, 12.10).

## Принципы

1. **Apple-минимализм: красиво, понятно, современно.** Серый фон, белые скруглённые карточки, крупные цифры, без лишних рамок и теней (просьбы 11.10 «в стиле Apple минимализм», 12.10 «современного и продуманного дизайна в стиле Apple»).
2. **Всё по-русски и понятно мне.** Никакого английского жаргона в интерфейсе: HRV, ACWR, REM, SpO₂ заменены русскими словами; непонятный термин объясняется в карточке «Что значат показатели» (просьбы 12.10 «абсолютно на русском языке», «HRV, ACVR… сделай на русском»).
3. **Смысл, а не просто цифры.** Каждое число сравнивается с личной нормой («▲ 4 к норме», «как обычно»), есть зона состояния и короткий вывод дня. Владелец хочет видеть прогресс и что подтянуть (просьба 12.10 «важно сам прогресс»).
4. **Научно и честно.** Советы опираются на исследования и нормы (ВОЗ 150 мин, 80–130% нагрузки), оценки ИИ помечены как оценки («граммы от ИИ — ошибка до 30–40%»), диагнозов не ставим (просьбы 12.10 «используя современные медицинские исследования», «исследование научно»; промпт 11.10 «не ставить диагнозы»).
5. **ИИ дёшево и прозрачно.** У каждого ответа ИИ видны модель и цена в ₽; рутину делает DeepSeek, тяжёлое — Claude; вся история хранится во «Все разборы» (просьбы 12.10 «один мой пром стоит 4 рубля 76 копеек», «DeepSeek… минимизировать расходы», «отдельно вкладки… сохранял сессиями»).
6. **Только для владельца, приватно.** Вход один, только владелец; сессия запоминается, повторный вход по письму не нужен; никаких фото и адресов зала (просьбы 12.10 «вход только один — это я», «сессия сохранялась», «фото зала в целом не надо»).
7. **iPhone прежде всего.** PWA с экрана «Домой», safe areas, нижняя панель вкладок, уведомления Web Push (просьбы 11.10 «мобильное приложение на iPhone», 12–13.10 про утреннюю сводку).
8. **Без лишнего.** Не показывать инструкции «как подключить» и выбор моделей в чате; не просить замеры, которые владелец не делает — только вес, рост, возраст (просьбы 12.10 «убери снизу, как подключить и какую модель выбрать», 13.10 «нужен вес, рост, возраст»).

## Язык и тексты

- **Обращение на «вы»**, коротко, по делу: «Повторить», «Разобрать заново», «Задайте пароль». Подписи кнопок — глагол или вопрос («Что делать сегодня?»).
- **Процесс** — глагол с многоточием и ожиданием: «Разбираю…», «Собираю…», «Тренер думает… обычно 10–40 секунд.», «Готовлю сводку… до минуты.»
- **Ошибка** — что случилось и что делать: «Нет связи с сервером.», «Сервис ИИ ответил ошибкой. Проверьте баланс и ключ.», «Почта или пароль не подошли. Если пароля ещё нет, войдите по ссылке и задайте его.»
- **Без английского** в видимом тексте (кроме названий моделей Claude/DeepSeek и бренда DDX). Названия упражнений — `name_ru`.

| Было (жаргон) | В интерфейсе |
|---|---|
| HRV | Вариабельность пульса (ВСР), «Вариабельность» в плитке |
| RHR | Пульс покоя |
| ACWR | Нагрузка недели к обычной, в % (80–130% — безопасно) |
| Readiness | Готовность, 0–100 |
| REM / Deep / Light / Awake | Быстрый / Глубокий / Лёгкий / Бодрств. |
| SpO₂ | Кислород ночью |
| Skin temp | Темп. кожи (отклонение от нормы, со знаком «+») |
| AZM | Минуты в зонах |
| TRIMP / cardio load | Нагрузка по пульсу, Кардионагрузка (баллы) |
| e1RM | Сила: расчётный максимум |

**Числа и единицы**
- Числа только через `num(v, digits)` из `lib/data.ts` (`toLocaleString("ru-RU")`): запятая в дробях, пробел в тысячах, `—` для пустых.
- Деньги — `rub()` из `lib/ai.ts`: `1,22 ₽`, `12,5 ₽`. Приблизительно — `≈ 1 ₽`.
- Даты/время — `fmtDay`, `fmtWeekday`, `fmtTime` (ru-RU, часовой пояс пользователя, для ИИ-меток `Europe/Moscow`).
- Единицы по-русски, после числа мелким `<small>`: `уд/мин`, `мс`, `ч`, `мин`, `ккал`, `г`, `кг`, `%`, `°C`, `вд/мин`, `баллов`.
- Сон: `7 ч 32 мин` в карточке, `7:32` в легенде колец.
- Отклонение: `<Delta>` → «▲ 4 мс к норме» / «как обычно».

## Компоненты

**Header** — заголовок экрана: надзаголовок (день недели и дата, или раздел строчными) + большой title.
```tsx
<Header eyebrow={fmtWeekday(today) + ", " + fmtDay(today)} title="Сегодня" />
<Header eyebrow="тренер" title="Разборы"><Link href="/coach" className="muted small">‹ Тренер</Link></Header>
```

**Card** — основа всего. Анатомия: цветная точка `<i>` + заголовок КАПСОМ в цвете домена, справа `right` (pill, цена, время) или шеврон `›` при `href`. Карточка с `href` — ссылка целиком.
```tsx
<Card title="Сон" color="sleep" href={`/sleep?d=${sleepDay?.day ?? ""}`} right={<span className="chev">{fmtTime(sleepDay.sleep_end, tz)}</span>}>
  <div className="val">7<small>ч</small> 32<small>мин</small></div>
  <div className="note">Глубокий 84 мин · быстрый 96 мин · <Delta value={...} base={sleepNorm} unit=" мин" good="up" /></div>
</Card>
```
Плитка метрики: `<Card title color href right={<span />}>` + `.val.m` + `<Spark>` + `<Delta>` в `.grid2.grid3`.

**Кольца + легенда** (`.rings-hero`, `ActivityRings`) — герой экранов «Сегодня» и «Питание». Порядок цветов всегда ring1 → ring2 → ring3 снаружи внутрь; легенда справа: `.k` капсом и `.v` крупно, `<small>/цель</small>`.
```tsx
<div className="ring-legend"><div>
  <div className="k" style={{ color: "var(--ring1)" }}>Готовность</div>
  <div className="v" style={{ color: "var(--ring1)" }}>{r ?? "—"}<small>/100</small></div>
</div></div>
```

**.state / .pill** — зона или статус: `<span className="state" style={{ color: `var(--${readinessColor(r)})` }}>Зелёная зона</span>`. `.pill` — то же без точки, для статуса в шапке карточки.

**.stats** — строка из трёх показателей «Профи» с разделителями 1px: `.k` подпись, `.v` число, ниже `<Delta>`. Ячейка может быть `<Link>`.

**Кнопки**
- `.btn` — главное действие, заливка `--air`, текст `--on-air` (белый днём, почти чёрный в тёмной теме), 17/600, во всю ширину карточки. Одна на карточку.
- `.btn.ghost` — второстепенное («Повторить», «Разобрать заново», «Прислать сводку сейчас»).
- `a.btn` — ссылка-кнопка: `<Link href="/coach/workout" className="btn" style={{ textAlign: "center" }}>Начать тренировку</Link>`.
- `.link` — текстовое действие цвета `--air` («Все разборы ›», «Войти по паролю»); `.link.small` в шапке карточки.
- `.chip` / `.chip.on` — фильтры и выбор режима в горизонтальной ленте `.chips` (или сетке `.food-add`).
- `.seg` / `<Seg>` / `<SpanSeg>` — переключатель периода «Н · М · 3М · 6М · Г».
- `.set-check` — квадратная отметка подхода (`.on` зелёный, `.fail` — «!» не сохранилось), `.scale-b` — шкала 1–5 в итогах тренировки.

**Списки**: `.list` > `.li` (две колонки, разделитель 0.5px, `.n` жирное имя, справа значение или `.chev`); `.plan-li` — упражнение с картинкой 52×40; `.check-row` — список покупок с галочками; `table.days` — таблица по дням в «Данных»; `.gloss` — раскрывающиеся `<details>` с «+/−».

**Формы**: `.field` (17px — iOS не зумит), фокус — обводка `--air`; `textarea.field`; `.form2` — две колонки с подписью `label` 13px `--muted`; `.field.code` — код из письма; `.set-row` — вес × повторы с единицей `<small>` внутри. Числовые поля с `inputMode="numeric"`, запятая принимается.
```tsx
<input className="field" type="password" autoComplete="new-password" minLength={6} required placeholder="новый пароль" aria-label="Новый пароль" />
```

**Картинки упражнений**: `.motion` (4:3, `.hero` 16:10, `.wide` 16:11) с кнопкой увеличения `.motion-zoom`; по тапу — полноэкранный `.viewer` с крупными кадрами. Только кадры техники, без фото зала.

**Чат и ИИ-текст**: `.bubble.me` (справа, тинт `--air`) / `.bubble.ai` (слева); ответ ИИ — через `<Md text=…/>` (`.md`, `.md-h`).

## Состояния

- **Загрузка**: заголовок экрана показывается сразу, ниже `<Loading n={3–4} />` — серые блоки 120px с мерцанием. Спиннеров нет. При `prefers-reduced-motion` анимации выключены.
```tsx
if (loading || !data) return (<><Header eyebrow={…} title="Сегодня" /><Loading n={4} /></>);
```
- **Ошибка загрузки**: `<ErrorCard error={error} onRetry={reload} />` — карточка с красноватой рамкой `.error`, «Не удалось загрузить данные», кнопка «Повторить»; для чужой почты — «Нет доступа» и «Выйти».
- **Ошибка действия** (сохранение, ИИ): строка `<p className="note" style={{ color: "var(--bad)" }}>` под формой; нет ключа ИИ — `--warn`.
- **Пусто**: карточка с `.note`, которая говорит, что здесь появится и как это получить: «Пока пусто. Каждый разбор и ответ ИИ сохраняется здесь: дата, модель и цена.», «Записей сна пока нет. Наденьте часы на ночь…». Нет данных в цифре — `—`, в зоне — «Мало данных» (`--muted`).
- **ИИ думает**: кнопка блокируется и меняет текст («Разбираю…»), над ней `.note` «Тренер думает… обычно 10–40 секунд.»; рацион — отдельная карточка «Составляю рацион». Предыдущий ответ остаётся на экране.
- **Оффлайн**: отдельного режима нет (решено 13.10: устаревшие данные хуже, чем их отсутствие). Service worker только для уведомлений, страницы не кэширует. Без сети — `ErrorCard` «Нет связи с сервером.» / «Нет связи с сервером ИИ.». Данные кэшируются в памяти на 5 минут (`lib/data.ts`).

## Графики

Все в `components/charts.tsx`, свой SVG в реальных пикселях (ширина через `ResizeObserver`), без библиотек.
- `ActivityRings` — концентрические кольца, `value` в долях цели; перевыполнение рисуется вторым кругом поверх (как в «Фитнесе»). Подложка — тот же цвет 22%.
- `Ring` — одиночное кольцо 0–100 с числом в центре; `.ring-center` + `.ring-center-v` — процент в центре кольца (кардионагрузка «103% цели»).
- `Spark` — мини-график 7 дней в плитке (линия или столбики), без осей.
- `Trend` — график по дням: столбики/линия/пунктир, стек (фазы сна), коридор нормы `band`, опорная линия `ref_` («среднее»). Палец или мышь ведёт по графику, значение выбранного дня показывается **в шапке** через `readout`, а не во всплывашке.
- `Hypnogram` (фазы сна), `HrLine` (пульс за день с пульсом покоя), `SleepSchedule` (время отхода/подъёма), `NormBar` (полоса с меткой нормы), `.week-bars` (столбики по дням недели), `.progress`.
- Подписи осей 10–12px `--muted`, сетка `--hair`, цвет серии — токен домена. Легенда — `.legend` с квадратиками 8px. Период — `SpanSeg`.

## Навигация и структура экранов

- `Shell` — нижняя панель из **5 вкладок**: Сегодня (`/`), Сон (`/sleep`), Питание (`/food`), Тренер (`/coach`), Данные (`/data`). Иконки — линейные SVG 25px, stroke 1.8; активная вкладка `--air`. Панель полупрозрачная с размытием, отступ снизу `env(safe-area-inset-bottom)`. От 900px панель становится боковой (220px) с логотипом «Здоровье **Лаб**».
- Новые экраны — **вложенные маршруты** существующих вкладок (`/coach/reports`, `/food/plan`, `/load`, `/report`, `/day`), шестую вкладку не добавлять. Возврат — ссылка «‹ Тренер» в `Header`.
- Порядок на экране: Header → герой (кольца/главная цифра + зона + вывод) → действие дня (ИИ-карточка, план) → детальные карточки домена → плитки → служебное (уведомления, пароль) → пояснения (глоссарий) → подпись источника данных.
- Тренер: План на сегодня (разминка 10 мин в начале, «Заменить упражнения») → Прогресс → ИИ-тренер → Разборы → Мой зал (DDX) → Цель → История → Каталог.
- Питание (в духе FatSecret): кольца КБЖУ → рацион на сегодня → добавление «Фото · Штрихкод · Текстом · Недавнее» → «Проверьте и добавьте» → дневник по приёмам пищи → неделя.
- `viewport-fit: cover`, `theme-color` светлый `#f2f2f7` / тёмный `#000`; полноэкранные слои (`.viewer`) учитывают `safe-area-inset-top/bottom`.
- Вход (`Login`): только почта владельца, пароль + запасная ссылка из письма; почта запоминается; регистрация новых людей выключена.

## ИИ в интерфейсе

- Все ответы ИИ — через `<AiCard kind day title cta hint color>`: показывает последний сохранённый ответ, кнопку («cta», затем «Разобрать заново» в стиле ghost) и строку `.ai-meta`: **дата · модель · цена** + ссылка «Все разборы (N) ›».
```tsx
<AiCard kind="daily" day={today} title="Тренер на сегодня" cta="Что делать сегодня?" color="ring1"
  hint="Короткий совет на день: тренироваться или восстанавливаться, что есть, во сколько лечь. По данным сна, пульса и нагрузки." />
```
- Цвета видов разборов — `KIND` в `lib/ai.ts` (совет на день ring1, тренировка load, недельный ring2, здоровье ring3, чат air, еда и рацион food). Новый вид — добавить туда.
- **По умолчанию дешёвая модель**: DeepSeek (≈0,3–1 ₽) — совет на день, чат, разбор тренировки, еда текстом; Claude (≈3–25 ₽) — недельный разбор, разбор здоровья, фото еды, рацион. Перед платным действием писать ориентир цены («≈ 1 ₽», «≈ 10–20 ₽»), бесплатное помечать «без ИИ, бесплатно».
- «Разборы» (`/coach/reports`): расход за месяц сверху, фильтры-чипы, каждый ответ с датой, моделью и ценой; у недельного разбора и разбора здоровья — ссылка на прошлый такой же. Неудачный платный запрос тоже сохраняется с причиной.
- Ключ ИИ только на сервере; в интерфейсе нет выбора модели, инструкций по ключам и провайдерам.
- Тон ответов: на «вы», с опорой на данные и исследования, без диагнозов; оценки ИИ помечать как оценки.

## Чек-лист перед изменением UI

- [ ] Новый экран — вложенный маршрут одной из 5 вкладок, не новая вкладка.
- [ ] Используются `Header`, `Card` (с `color` домена), `.btn`/`.btn.ghost`/`.link`/`.chip`, а не новые стили.
- [ ] Цвета только через токены; цвет домена совпадает с таблицей выше.
- [ ] Весь текст по-русски, на «вы», без HRV/ACWR/REM/SpO₂; новый термин добавлен в глоссарий «Что значат показатели».
- [ ] Числа через `num()`, деньги через `rub()`, даты через `fmt*`; единицы в `<small>`.
- [ ] Есть состояния: `Loading`, `ErrorCard`/строка ошибки, пустое состояние с подсказкой, `—` для нет данных.
- [ ] Значение сравнивается с нормой (`Delta`, зона), где это имеет смысл.
- [ ] ИИ-действие показывает модель и цену, пишет историю в «Разборы», по умолчанию дешёвая модель.
- [ ] Проверено в светлой и тёмной теме и на ширине iPhone (375px; до 380px кольца встают в столбик).
- [ ] Учтены safe areas; нижний контент не прячется под панель вкладок.
- [ ] Поля ввода 16–17px, у кнопок и полей есть `aria-label`/подпись, фокус виден.
- [ ] Нет лишних данных и фото: только то, что владелец реально измеряет (вес, рост, возраст).

- Не возвращать английские термины и аббревиатуры в подписях (HRV, ACWR, REM) — владелец прямо просил перевести (12.10).

- Не использовать Claude там, где справится DeepSeek (12.10, расходы).
- Не просить замеры тела, процент жира и прочее — только вес (13.10).
- Не выкидывать на повторный вход по письму: пароль один раз, сессия помнится (12.10).
